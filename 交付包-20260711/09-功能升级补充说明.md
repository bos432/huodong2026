# 功能升级补充说明

补充日期：2026-07-11

## 1. 报名批量审核

PC 后台“报名管理”新增：

- 待审核报名多选框。
- “批量通过”操作。
- “批量拒绝”操作和统一拒绝原因。
- 成功数、失败数和首条失败原因反馈。
- 单次最多处理 100 条报名。

后端不会直接批量改状态，而是逐条复用原审核业务规则：

- 校验管理员角色和租户数据范围。
- 只有待审核报名可以通过。
- 付款状态不满足时拒绝通过。
- 拒绝报名时同步处理待付款订单和积分返还。
- 每条报名保留原操作日志，另增加批量操作汇总日志。

自动验收保留数据：

| 数据 | 内容 |
| --- | --- |
| 活动 ID | `143` |
| 批量通过报名 | `221`、`222` |
| 批量拒绝报名 | `223`、`224` |
| 活动名称 | `【批量审核验收保留】1783737501112` |
| 验收结果 | 通过 2 条、拒绝 2 条、失败 0 条 |

回归命令：

```bash
npm run acceptance:functional-upgrades
```

该命令会创建新的保留活动和四条报名，同时验证批量通过、批量拒绝、最终状态及审计日志。

## 2. 添加到日历

用户端新增两个入口：

- 活动详情 -> 快捷操作 -> 添加到日历。
- 报名成功/已签到详情 -> 添加到日历。

平台行为：

- H5：生成标准 `.ics` 日历文件，包含活动标题、开始时间、结束时间、地点、说明和提前 30 分钟提醒。
- 微信小程序：调用 `wx.addPhoneCalendar` 写入系统日历。
- 其他不支持系统日历的平台：复制活动标题、时间和地点，方便用户手工保存。

原来的“活动提醒”仅显示提示，没有真正写入提醒。本次升级后已替换为实际日历能力。

- 服务器需要重新构建并重启 API。
