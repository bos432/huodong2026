## 交付前必须做的安全动作

1. 修改所有后台测试账号密码，停用不需要的验收账号。
2. 正式环境使用随机强密码设置 `JWT_SECRET`、`H5_AUTH_SECRET` 和数据库密码。
3. 正式环境设置 `H5_AUTH_MODE=sms`，不要使用开发验证码。
4. 在真实支付证书、回调验签和预发证据完成前，保持真实支付开关关闭。
5. 数据库已有数据时必须保持 `DB_SYNCHRONIZE=false`，通过 migration 管理结构变更。
