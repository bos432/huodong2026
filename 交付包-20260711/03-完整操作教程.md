# 完整操作教程

## 1. 入口说明

| 入口 | 本地地址 |
| --- | --- |
| H5 用户端 | `http://127.0.0.1:18080/?tenantCode=qiwai-showcase` |
| PC 管理后台 | `http://127.0.0.1:18080/admin/` |
| 移动管理端 | H5 登录后进入手机管理，或使用对应管理路由 |
| API 健康检查 | `http://127.0.0.1:18080/api/health/ready` |

线上交付时把域名替换为正式域名。

## 2. 普通用户操作

### 登录

1. 打开 H5 用户端。
2. 进入“我的”或需要登录的活动。
3. 输入手机号 `13990000002`。
4. 本地开发环境填写验证码 `123456`。
5. 正式环境验证码由短信供应商发送。

### 报名活动

1. 进入“活动”，选择报名中的活动。
2. 查看时间、地点、票种、价格和退款规则。
3. 点击报名，填写姓名、手机号、微信号及自定义报名字段。
4. 提交后按活动规则进入待审核、待付款或报名成功状态。
5. 付费活动选择可用支付方式完成付款。

### 查看订单与签到

1. 进入“我的”或报名详情。
2. 查看报名状态、订单状态、付款金额和签到二维码。
3. 到场后向签到员出示二维码或签到码。
4. 核销后页面显示“已签到”。

### 商城与课程

1. 商城中选择商品、SKU、优惠券和收货地址后下单。
2. 跨店订单会按履约店铺拆分，微信支付订单需按店铺逐单支付。
3. 在商城订单中查看物流、申请售后和查看退款状态。
4. 课程可在课程详情购买，之后从“我的学习”进入。

## 3. 平台超级管理员

账号：`admin`。

主要职责：

- 管理租户、区域和平台级配置。
- 查看跨租户运行情况。
- 管理平台管理员与角色权限。
- 检查部署版本、系统健康和审计日志。

操作建议：平台账号只授予少数运维负责人，日常商家运营使用租户账号。

## 4. 商家管理员

账号：`showcase_admin`。

### 创建活动

1. 登录后台，进入“活动管理”。
2. 新建活动，填写标题、主办方、时间、地点、人数和报名规则。
3. 配置免费或付费票种、审核规则、退款规则和签到设置。
4. 保存草稿，检查前台预览后发布。

### 管理报名

1. 进入活动的报名列表。
2. 按状态筛选待审核、待付款、已报名、已签到等记录。
3. 审核需要人工确认的报名。
4. 导出报名表，用于现场或财务核对。

### 页面与营销

1. 在前台装修中配置首页、内页区块和底部导航。
2. 在营销弹窗中创建弹窗，设置时间、页面和启用状态。
3. 在广告中心上传图片、设置跳转和投放位置；没有图片的广告不能启用。

### 系统设置

1. 配置品牌、客服、短信、微信和支付参数。
2. 检查 API/Admin/H5 版本是否一致。
3. 修改默认管理员密码并定期查看登录日志。

## 5. 运营账号

账号：`showcase_ops`。

- 负责活动创建、内容维护、报名处理和移动管理端。
- 移动管理首页可查看活动总数、待审核、累计报名和本月报名。
- 不需要平台级配置权限，避免使用超级管理员做日常运营。

## 6. 财务账号

账号：`showcase_finance`。

1. 查看活动订单、商城财务和结算记录。
2. 确认线下收款时核对订单号、用户和金额。
3. 处理退款申请，检查退款金额、公益金保留规则和支付流水。
4. 使用财务导出和对账入口进行日结、周结和月结。
5. 财务账号不能进入营销弹窗等无关模块。

## 7. 签到账号

账号：`showcase_checkin`。

1. 进入签到核销。
2. 扫描用户签到二维码，或手动输入签到码。
3. 核对用户、活动和报名状态。
4. 点击确认核销。
5. 成功后页面显示“已签到”，重复核销应被阻止或明确提示。

## 8. 店铺与代理

### 店铺负责人

账号：`showcase_store_owner`。

- 管理本店商品、库存、订单和履约。
- 只能查看授权店铺数据。

### 店铺财务

账号：`showcase_store_finance`。

- 查看本店订单、财务和结算。
- 不具备商品编辑权限。

### 代理负责人

账号：`showcase_agent_owner`。

- 查看代理范围内的业务和结算。
- 不能跨代理或跨租户访问数据。

## 9. 日常运维建议

每日：检查 health、PM2、失败通知、待退款、待审核和异常支付。

每周：执行数据库备份恢复抽查、管理员登录审计、权限账号复核和依赖审计。

每月：轮换高权限账号密码、检查证书有效期、清理过期备份、复核支付对账和短信余额。
