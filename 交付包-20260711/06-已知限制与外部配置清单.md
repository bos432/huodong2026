# 已知限制与外部配置清单

## 1. 正式支付

正式微信/支付宝支付需要甲方提供并配置：

- 微信支付 AppID、商户号、API v3 key。
- 商户私钥、证书序列号、平台证书。
- 可公网访问的支付和退款回调地址。
- 支付场景、商户直收和代理结算所需权限。
- 支付、退款、对账单、异常回调的预发验收证据。
- 支付宝 AppID、应用私钥和公钥证书，仅在启用支付宝时需要。

在这些配置和证据完成前，保持 `REAL_PAYMENT_ENABLED=false` 及相关 rollout 开关为 false。系统不会把未配置的真实支付伪装成成功。

## 2. 正式短信

需要甲方提供：

- 短信供应商账号和密钥。
- 已审核通过的短信签名。
- 已审核通过的登录验证码模板。
- 腾讯云场景下的 SDK AppID，或其他供应商要求的参数。
- 生产域名/IP 白名单和短信余额。

配置后设置 `SMS_PROVIDER_ENABLED=true`、`H5_AUTH_MODE=sms`，再验证发送、频率限制、错误提示和登录闭环。

## 3. 微信小程序

需要甲方提供：

- 小程序 AppID 和管理员/开发者权限。
- 微信开发者工具登录权限。
- request、uploadFile、downloadFile 等合法域名。
- 隐私协议、用户信息和手机号能力对应的审核资质。

必须在开发者工具和至少一台真实手机上验证微信登录、手机号绑定、页面分享、支付、签到二维码和网络权限。

## 4. 生产基础设施

- 正式域名、HTTPS 证书和备案。
- MySQL 生产实例或持久化 Docker 卷。
- 上传文件持久化和对象存储策略。
- 数据库异地备份和恢复演练。
- 日志、告警、短信余额和支付证书到期监控。

## 5. 当前非阻塞警告

- Admin 构建仍有 VueUse PURE 注释位置提示和单个大 chunk 提示，不影响构建和功能。
- uni-app 提示可升级 alpha 版本，当前稳定构建无需升级。
- 工作区尚未提交，因此发布巡检提示存在未提交改动。

## 6. 正式上线判定

源码和本地环境已满足交付条件。只有在支付、短信、小程序真机和生产基础设施完成后，才能把“可部署交付”提升为“可承载真实用户和真实资金的正式运营”。
