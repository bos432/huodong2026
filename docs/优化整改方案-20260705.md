## 建议后续优化

### 1. 增加平台超管验收脚本参数

现有线上 smoke 脚本要求平台超管账号密码。建议后续增加“商家模式验收”，允许在未提供平台超管密码时完整验证商家、用户、财务、签到链路，并将平台能力标记为 skipped。

### 2. 固化手机端管理端自动化验收

本次用临时 Playwright 脚本验证了 H5 版手机管理端。建议把它固化为：

```bash
npm run browser:mobile-admin
```

覆盖：

- 登录
- 工作台
- 活动列表
- 新建/保存/发布
- 报名列表
- 订单列表
- 签到核销

### 3. 小程序体验版验收清单固定化

建议在后台“小程序发布”页增加上传后验收清单：

- 未登录“我的”页能返回首页
- 首次头像昵称获取后不再重复强制获取
- 活动详情报名
- 报名详情签到码
- 手机管理端保存/发布活动
- 签到扫码/输入核销

### 4. 配置体检 warning 细化

线上 health 返回 `config=warning`。建议平台超管进入“配置体检”确认 warning 是否为短信/邮件/微信订阅消息等可选项，并将“可上线 warning”和“必须处理 warning”区分显示。
