# PC 后台移动导航整改验收（2026-07-20）

## 问题

原 PC 后台在 `<=768px` 时把全部一级菜单横向排列，并通过页面顶部横向滚动访问。390px 视口只能看到部分分组，菜单被截断且占用额外高度，不适合作为移动管理入口。

## 整改

- 桌面端继续使用 248px 左侧常驻导航，不改变现有操作习惯。
- 移动端改为 54px 品牌栏和图标菜单按钮，隐藏桌面侧栏。
- 主导航使用左侧抽屉，复用同一权限、数据范围、套餐和功能开关过滤结果。
- 菜单按钮和关闭按钮分别提供 `打开主导航`、`关闭主导航` 无障碍名称和 title。
- 选择菜单或路由变化后自动关闭抽屉；抽屉内部支持纵向滚动。
- 当前路由使用 `route.path` 高亮，带 `tenantId/merchantId` 查询参数时不会丢失活动菜单状态。
- 修复抽屉 teleport 导致 scoped 样式失效的问题，抽屉主体、品牌栏和菜单统一为后台深色导航样式。
