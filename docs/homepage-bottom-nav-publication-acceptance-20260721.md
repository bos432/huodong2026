# 首页底部导航发布与隐藏整改验收

更新时间：2026-07-21

## 问题结论

当前现象由两层问题叠加造成：

1. 租户 `23 / qiwai-showcase` 的装修草稿已经把“专题、共修”设为停用，但公开 H5 仍读取 2026-07-17 的旧发布快照；旧快照中 5 项全部启用。
2. 装修编辑器保存成功提示错误写成“刷新前台预览即可查看最新效果”，与已经启用的草稿/发布机制矛盾。整块底部导航停用时，公开服务还会过滤停用模块，前端可能将其误判为“未配置”并恢复默认菜单。

## 整改

- 保存按钮及成功提示统一明确为“保存草稿”，不再承诺刷新即生效。
- 装修页有未发布修改时显示醒目警告和“立即发布到 H5”操作；线上预览入口统一命名为“当前线上 H5”。
- 公开服务保留已停用的 `bottom_nav`、`my_page`、`inner_pages` 单例标记，但继续过滤其他停用内容，既避免默认底栏复活，也不泄漏停用内容。
- 发布快照比较改为递归稳定键序，避免 MySQL JSON 对象键重排后误报“有未发布修改”。
- 已将用户当前首页草稿发布为版本 `5`，版本历史和原数据均保留。

## 后续操作规则

装修模块的“保存草稿”只保存编辑结果；确认整体效果后点击“发布当前草稿”或“立即发布到 H5”，公开 H5 才读取新快照。小程序仍需重新构建和上传才会获得最新静态版本。
