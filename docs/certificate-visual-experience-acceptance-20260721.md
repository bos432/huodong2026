# 证书成品预览与下载整改验收

更新时间：2026-07-21

## 问题

- 志愿者档案的证书弹窗只显示数据表，缺少证书成品预览、下载和公开验真入口。
- 原弹窗固定宽度且列宽总和超过可视区域，发证时间和操作列在较窄窗口中被裁切。
- H5“我的证书”在 `imageUrl` 为空时只显示“证”字占位，虽然已有 SVG 下载能力，但用户无法直接看到证书图。

## 整改

- 新增统一 `1200x840` SVG 证书渲染器，覆盖志愿服务、公益大使、城市共建和课程结业证书；撤销证书显示明显水印。
- 后台增加受平台权限保护的证书成品接口，弹窗改为证书列表与成品预览双栏布局，提供预览、下载、公开验真和撤销入口。
- H5 证书响应增加公开脱敏缩略图地址；无自定义封面时直接显示动态证书图，下载仍返回仅本人可访问的完整姓名版本。
- 文件名继续执行非法字符替换和 80 字符限制；SVG 文本统一 XML 转义，下载与预览响应保留 CSP、nosniff 和缓存边界。
