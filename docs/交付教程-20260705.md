## 发布活动

PC 后台：

1. 登录 `showcase_admin` 或 `showcase_ops`。
2. 进入“活动管理”。
3. 点击新建活动。
4. 填写标题、封面、详情、报名时间、活动时间、容量、票种/价格、报名字段、入群二维码。
5. 先保存草稿，确认列表能看到。
6. 点击发布。
7. 如果商家配置不要求平台审核，活动状态会直接变为开放；如要求审核，需要平台超管审核。

手机管理端：

1. 打开 `https://rd.chaimen666.com/?tenantCode=qiwai-showcase#/pages/admin/login`。
2. 登录 `showcase_ops / Qiwai123456`。
3. 进入“活动”。
4. 新建或编辑活动。
5. 保存后点击发布。

## 用户报名

1. 打开 H5 前台。
2. 进入活动详情。
3. 点击报名。
4. 登录用户账号，演示用户可用 `13988988474 / Qiwai123456`。
5. 填写报名字段并提交。
6. 免费活动会直接报名成功；收费活动按配置走余额支付、线下支付或其他支付方式。
7. 报名成功后进入“我的报名”查看报名详情和签到码。

## 入群二维码

- 活动公开详情页不直接展示群二维码。
- 报名成功或报名详情页展示入群流程提示。
- 活动单独配置的群二维码优先；没有配置时使用“系统设置 -> 运营设置 -> 默认入群二维码”。

## 现场签到

扫码方式：

1. 签到员登录手机管理端或 PC 后台。
2. 进入“签到核销”。
3. 扫用户报名详情里的签到二维码。
4. 系统提示核销成功。

手工方式：

1. 用户打开“我的报名 -> 报名详情”。
2. 向签到员展示签到码。
3. 签到员在签到页输入签到码并提交。

## 财务和订单

1. 登录 `showcase_finance / Qiwai123456`。
2. 进入订单或财务相关页面。
3. 查询报名用户手机号、订单号、退款记录和余额流水。
4. 线下收款订单由财务确认收款。
5. 退款按“用户申请/后台发起 -> 财务审核 -> 完成退款”流程处理。

## 短信配置

路径：

```text
PC后台 -> 系统设置 -> 运营设置 -> 短信验证码服务
```

螺丝帽填写：

```text
短信服务：启用
短信服务商：luosimao-sms
短信 Key：留空
短信 Secret/API Key：填螺丝帽完整 API Key，例如 key-xxxx
短信签名：填已审核签名，不带【】
模板 ID：留空
短信 AppID：留空
```

保存后点击“发送测试短信”确认真实短信可达。

## 首页装修图片广告

1. 登录商家管理员。
2. 进入“首页装修”。
3. 添加“图片广告”模块。
4. 可上传多张图片。
5. 每张图片可单独设置跳转链接。
6. 保存后到 H5 首页确认轮播和跳转。

## 小程序发布

1. 本地或服务器执行小程序构建：

```bash
export VITE_API_BASE=https://rd.chaimen666.com/api
export VITE_DEFAULT_TENANT_CODE=qiwai-showcase
npm --prefix apps/mobile run build:mp-weixin
```

2. 打开微信开发者工具。
3. 导入：

```text
apps/mobile/dist/build/mp-weixin
```

4. 体验版自测：登录、我的页、活动详情、报名、报名详情、签到码、手机管理端活动发布、签到核销。
5. 自测通过后提交审核。
