# H5 预览地址整改验收

更新时间：2026-07-21

## 问题

本地 Docker 统一入口运行于 `http://127.0.0.1:18080`，但后台公共 H5 预览工具对所有本地主机强制使用历史开发端口 `5273`。该端口当前没有服务，因此活动预览、商家 H5、首页装修、二维码和复制链接会出现 `ERR_CONNECTION_REFUSED`。

## 整改

- 显式配置 `VITE_H5_ORIGIN` 时继续优先使用配置值。
- 后台开发服务器运行于 `5174` 时，默认映射到标准 H5 开发端口 `5173`。
- Docker、Nginx 或其他同源部署场景直接使用当前页面 `window.location.origin`，因此本地候选环境统一生成 `http://127.0.0.1:18080`。
- 删除历史 `5273` 默认回退，并增加源码合同测试，防止旧端口再次进入预览地址。

## 验收结果

| 验收项 | 结果 |
|---|---|
| 源码合同 | `operation-guide-contract.spec.ts` 5 项通过 |
| PC 后台生产构建 | 通过 |
| 首页装修预览链接 | `http://127.0.0.1:18080/?tenantCode=qiwai-showcase#/pages/index/index` |
| 活动详情预览 | 活动 `192` 在 `18080` 正常显示名称、报名状态、名额、时间、地点和报名按钮 |
| H5 首页预览 | 慢π演示中心首页、精选活动及装修内容正常显示 |
| 页面宽度 | 活动详情及首页均 `scrollWidth=clientWidth=1280` |
| 浏览器日志 | warning/error 0 |

## 影响范围

使用 `apps/admin/src/h5-preview.ts` 的活动 H5、商家 H5、装修页、活动海报、二维码和复制链接统一获得修复。正式环境如 H5 与后台不同域，仍应在构建时显式设置 `VITE_H5_ORIGIN`。
