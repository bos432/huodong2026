# H5 活动详情游客验收与时区整改记录

验收日期：2026-07-17

## 发现与原因

活动详情页原先直接截断 UTC ISO 字符串，导致 API 的 `2026-07-17T15:00:00Z` 被显示为 `15:00`，而首页卡片按本地时间显示为 `23:00`，造成同一活动时间不一致、报名截止时间看似已过的问题。

## 整改

`apps/mobile/src/pages/activity/detail.vue` 的 `formatTime()` 现在使用 `Date` 和浏览器本地时区格式化，保留 `YYYY-MM-DD HH:mm` 格式；非法日期保留安全降级文本。

## 复验

- 活动 ID：`131`，租户：`qiwai-showcase`。
- 详情时间真实显示：`2026-07-17 23:00 - 2026-07-18 01:00`。
- 截止时间真实显示：`2026-07-17 06:00`。
- 活动标题、状态、地点、费用、余量、地图入口、分享、客服和报名入口均可见。
- API 仍返回 `displayStatus=open`，与截止时间的 UTC 时刻一致。
- 控制台 error/warning：0。
