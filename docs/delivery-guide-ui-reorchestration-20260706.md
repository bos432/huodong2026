## 4. 平台超管操作

1. 打开 `http://127.0.0.1:5174/admin/login`。
2. 使用 `admin / Admin123456` 登录。
3. 查看平台菜单：平台总览、商家管理、活动监管、财务监管、会员资产、运营内容、扩展商城、扩展专题共修、扩展公益招募、系统安全。
4. 在“商家管理”查看 `慢π演示中心(qiwai-showcase)`。
5. 在“运营内容”查看首页装修、营销弹窗、广告中心。
6. 在“系统安全”查看系统设置、小程序发布、操作日志。

## 5. 商家运营操作

1. 使用 `showcase_admin / Qiwai123456` 或 `showcase_ops / Qiwai123456` 登录后台。
2. 进入“活动运营 -> 活动管理”，新建或编辑活动。
3. 配置活动标题、时间、地点、报名字段、票种和详情。
4. 发布活动后，进入 H5 首页或活动列表查看。
5. 进入“报名签到 -> 报名管理”查看报名记录。
6. 进入“装修营销 -> 首页装修/营销弹窗/广告中心”维护前台运营内容。

## 6. H5 用户报名流程

1. 打开 `http://127.0.0.1:5173/?tenantCode=qiwai-showcase#/`。
2. 首页点击“活动报名”或“近期活动”。
3. 进入活动详情，点击“立即报名”。
4. 登录：手机号 + 验证码，或使用演示会员手机号 + 密码。
5. 填写报名信息，收费活动选择线下收款或余额支付。
6. 提交后进入“我的报名/报名详情”查看状态。
7. 财务确认收款后，报名详情可查看签到码。

## 7. 财务收款与退款

1. 使用 `showcase_finance / Qiwai123456` 登录后台。
2. 进入“订单财务 -> 订单管理”。
3. 用手机号或订单号筛选待付款订单。
4. 点击“收款/确认收款”，填写备注后确认。
5. 进入“财务对账”查看订单、退款、余额流水。
6. 如需退款，在订单或退款列表发起/审核退款。

## 8. 签到核销

1. 用户在 H5 报名详情查看签到码。
2. 使用 `showcase_checkin / Qiwai123456` 登录后台。
3. 进入“报名签到 -> 签到核销”。
4. 输入签到码，可填写现场备注，点击核销。
5. H5 报名详情刷新后显示“已签到”。

## 9. 手机管理端

1. 打开 H5 后访问 `#/pages/admin/login`，或从管理入口进入。
2. 使用 `showcase_ops / Qiwai123456` 登录。
3. 工作台可查看最近活动。
4. 进入活动列表，新建活动，保存草稿，再发布。
5. 查看报名、订单、签到核销入口。

## 10. 商城商品与优惠券

1. 使用 `showcase_store_owner / Qiwai123456` 登录后台。
2. 进入“扩展 · 商城 -> 商品管理”。
3. 店铺选择 `慢π自营店`，本地可直接访问 `http://127.0.0.1:5174/admin/mall-products?merchantId=2`。
4. 点击商品“编辑”，修改标题、图片、价格、库存、上下架状态或配送/售后说明后保存。
5. 点击“优惠券”，可新增、编辑、启停优惠券。

本次已复验：商品和优惠券保存不会再提交后端只读字段，因此不会触发 `should not exist` 类严格校验错误。

## 11. 小程序交付

构建必须使用 Node 22/24：

```powershell
$env:PATH='C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin;' + $env:PATH
npm --prefix apps/mobile run build:mp-weixin
```

线上优先使用后台发布管理：

1. 进入后台“系统安全 -> 小程序发布”。
2. 确认 AppID、AppSecret、CI 私钥、版本号和构建目录已保存。
3. 点击“上传体验版”，用右侧二维码体验检查首页、活动报名、我的报名、签到码和手机管理端。
4. 确认无误后点击“提交微信审核”。
5. 审核通过后点击“发布线上版”。

微信开发者工具导入 `apps/mobile/dist/build/mp-weixin` 仅作为后台上传失败时的兜底流程。

本次改动涉及 `apps/mobile`，必须重新上传并提交审核。
