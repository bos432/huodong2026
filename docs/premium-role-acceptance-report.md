## 5. 缺陷与整改

1. 志愿总览和写链路在真实数据下因 TypeORM eager 循环关系展开出现单核 100% 且不返回。总览改为显式 QueryBuilder，录取、人数、幂等、证书和证明查询改为关闭 eager 的标量查询；录取约 59 ms，总览约 18-65 ms，发证约 54 ms。
2. 论坛回复 DTO 缺少真实审核状态和层级，现返回 `status` 与 `depth`，预审回复可正确显示 `pending`。
3. 志愿证书原来可能缺少租户归属，现从最近确认服务任务写入 `tenantId`，旧同名证书同步补齐。
4. 编排器恢复阶段遇到瞬时网络错误会留下临时权限。现对套餐、角色权限和密码恢复增加有限重试，并逐项回读断言；只有全部恢复成功才写 `status=passed`。
5. 编排器曾将 `showcase_admin` 密码改成统一夹具密码，浏览器脚本也误用会员密码。现按账号使用既定密码并在清理阶段恢复，默认线上演示冒烟重新通过。
6. 根构建在 Node 25 下被移动端 Node 22 门禁中止。新增 H5 构建适配器，自动使用仓库内 Node `22.14.0`，不降低版本约束；根 `npm run build` 已完整通过。
