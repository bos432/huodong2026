## 越权缺陷与整改

真实验收首次发现租户运营账号可读取平台分群 ID 1 的快照，接口错误返回 200。根因是分群使用了允许平台公共数据的通用租户断言。

整改后分群采用严格作用域：

- 平台作用域只能访问 `tenantId=null` 的分群和快照。
- 租户作用域只能访问与当前 tenantId 完全一致的数据。
- 分群更新、快照创建、快照列表和快照成员四类 ID 入口统一执行严格判断。
