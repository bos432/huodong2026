## 3. 活动运营教程

1. 登录 `showcase_admin` 或 `showcase_ops`。
2. 进入“活动运营 / 活动管理”。
3. 新建活动，填写标题、封面、活动时间、报名时间、地点、容量、票种和报名字段。
4. 保存草稿后检查列表。
5. 发布活动；如商家开启平台审核，需要平台超管审核后公开。
6. H5 打开活动详情，确认报名按钮、费用、地点、报名字段显示正常。

## 4. 报名字段教程

1. 活动编辑页进入报名字段设置。
2. 增加字段后保存活动。
3. 用 H5 用户报名一次。
4. 后台报名列表查看字段是否回显。
5. 导出 Excel，确认字段同步出现。
6. 删除字段前先确认是否已有历史报名；建议不物理删除历史字段，只停用或改为非必填。

## 5. 用户报名和签到教程

用户侧：

1. 打开 H5 前台。
2. 进入活动详情。
3. 手机号登录。
4. 点击报名并提交。
5. 进入“我的 / 我的报名 / 报名详情”查看签到码。

签到员侧：

1. 登录 `showcase_checkin / Qiwai123456`。
2. PC 后台进入“报名签到 / 签到核销”，或手机管理端进入“签到核销”。
3. 可以扫码核销，也可以手工输入签到码核销。
4. 核销后用户报名详情显示已签到。
