## 2. 静态审计与整改

使用 Vue SFC/模板 AST 审计 70 个 `.vue` 文件，识别没有文本、`aria-label` 或 `title` 的按钮。整改前共 11 个：

- 活动编辑主理人删除按钮 1 个。
- 首页装修模块复制/删除按钮 2 个。
- 首页装修快捷入口、底部菜单、我的页入口和内页配置删除按钮 8 个。

整改后所有纯图标按钮同时具备对象级 `aria-label` 和命令 tooltip，例如“复制模块：心得烟测模块 1782228351081”“删除主理人：主理人名称”。AST 复扫未命名按钮为 0。

新增 `admin-accessibility-contract.spec.ts`，持续检查：

- 所有自闭合图标按钮必须同时具备 `aria-label` 和 `title`。
- 后台壳层必须提供 `role=status`、`aria-live=polite` 和原子播报。
- 路由切换后必须解析 Element Plus 组件 `$el` 并聚焦主内容。

## 3. 路由播报与焦点

后台壳层新增隐藏状态区，页面名称来自权限菜单的同一标签源。主内容使用 `tabindex=-1` 和动态 `aria-label`。

首次实现直接调用模板引用的 `focus()`，浏览器实测发现 `el-main` 引用是组件实例，切页后焦点仍在 `BODY`。整改为兼容原生元素及组件 `$el` 后复验：

| 流程 | 状态播报 | 主内容标签 | 当前焦点 | 控制台 |
| --- | --- | --- | --- | --- |
| 会员资料管理 -> 全部活动 | 已进入全部活动 | 已进入全部活动 | `MAIN` | 0 warning/error |
| 全部活动 -> 前台全局装修 | 已进入前台全局装修 | 已进入前台全局装修 | `MAIN` | 0 warning/error |

前台装修页实际可见纯图标按钮全部返回对象级名称和 tooltip，未命名可见按钮为 0。
