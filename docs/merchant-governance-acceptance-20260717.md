# 09.01 商户入驻治理验收报告（2026-07-17）

## 验收范围

- H5/小程序商户申请、资质文件上传、个人申请历史和审核结果。
- 租户后台申请审核、自动建店、资质、合同、费率、结算周期和开店门禁。

## 本次整改

1. `mall.merchant.manage` 原被标记为平台专属，租户超级管理员无法治理自己的店铺；已统一修正 API 权限目录、PC 权限目录、路由和租户菜单。
2. 店员授权更新原可借其他授权 ID 改写账号或店铺归属，且平台无租户账号可挂入租户店铺；现要求授权身份不可变且账号必须与店铺同租户。
3. 未指定授权生效时间时原写入当前时间，在 MySQL 时区配置下可能变成未来 8 小时；现以 `NULL` 表示立即生效。
4. PC 商户页原无条件加载平台租户列表，租户管理员收到 403 后初始化中断；现仅平台管理员加载租户列表，租户管理员使用当前租户。H5 申请时间统一按 `Asia/Shanghai` 展示。
