## 整改记录

1. 追评、评价举报创建和平台处理举报改为显式加载必要关系，避免 TypeORM eager relation 触发 MySQL 61 表 join 上限。
2. 修复评价举报处理时租户、评价、商户和订单关系加载不完整的问题。
3. 秒杀订单并发命中 `clientOrderKey` 唯一约束时，按租户、用户和业务键回读原订单或结算组，恢复为业务幂等响应。
4. 验收脚本升级为自登录、自发现可追评评价、自建优惠券并自动复用当前有效秒杀，可重复执行且不清理历史数据。
