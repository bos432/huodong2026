## 5. 发现与修复

发现问题：后台关闭“共修动态/心得”后，用户仍可通过动态详情直达链接先读取正文、图片和评论，再看到关闭弹窗；相关公开 API 也仍会返回数据。

修复内容：

- H5 共修首页和动态详情先读取功能开关并执行页面访问保护。
- 功能关闭时停止请求和渲染动态内容。
- API 为共修活动、动态、评论、互动、收藏、通知和关注增加服务端 `community` 门禁。
- 发布心得接口增加 `communityPublish` 门禁。
- 增加客户端状态一致性和公开内容边界合同测试。
