# 论坛底部导航整改验收

更新时间：2026-07-21

## 问题

“我的论坛”页面只渲染帖子、回复和收藏内容，没有统一底部导航，也没有页面内返回入口。H5 空数据场景下用户无法直接返回“我的”或切换到其他主栏目。论坛首页和帖子详情也未渲染底部导航，浏览体验与其他主业务页面不一致。

## 整改

- “我的论坛”增加统一底部导航并高亮“我的”。
- “我的论坛”增加顶部返回、标题和刷新操作，帖子/回复/收藏标签补齐键盘操作和选中语义。
- 论坛首页和帖子详情增加统一底部导航并高亮“共修”。
- 发帖编辑页不增加底栏，避免用户误触离开后丢失未提交内容。

## 影响范围

本次只改变论坛浏览和个人论坛记录页的导航，不修改帖子、回复、收藏数据及论坛业务状态。既有数据全部保留。
