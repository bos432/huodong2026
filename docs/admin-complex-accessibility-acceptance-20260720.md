- 日期：2026-07-20
- 环境：`http://127.0.0.1:18080/admin`
- 页面：课程管理、课程考核双层弹窗、前台全局装修。

## 2. 静态审计与整改

- 审计 70 个 PC 后台 Vue 模板，共发现 21 个真实非原生点击控件缺少完整键盘语义。
- 覆盖扫码关闭/手工输入、活动状态标签、看板待办与告警、首页装修套装/模块/预览、巡检周期、订单备注和系统设置快捷入口。
- 全部补齐 `role=button`、`tabindex=0`、Enter、Space，并增加统一 `focus-visible` 轮廓。
- 复扫点击型 `div/span/article/el-tag` 后，排除 `click.self/click.stop` 遮罩，剩余缺口为 0。
- 审计 59 个后台页面、245 个 Element Plus 表格，原有表格自身可访问名称为 0；列头由组件正确输出为 `columnheader`。

新增 `apps/admin/src/accessibility.ts`：

- 优先使用弹窗 `aria-label` 作为动态表格名称。
- 其次使用最近卡片、标签页、分区标题或页面主标题。
- 同一上下文有多张表时自动追加稳定编号。
- 使用 `MutationObserver` 覆盖异步加载和弹窗动态挂载，Layout 卸载时断开观察器。
- 已有人工 `aria-label` 的表格不会被覆盖。
