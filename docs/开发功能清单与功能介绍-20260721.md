# 活动报名平台开发功能清单与功能介绍

> 更新日期：2026-07-21  
> 覆盖范围：PC 管理后台、H5、微信小程序、移动管理端、API、多租户 SaaS 与部署运维  
> 当前结论：P0-P3 本地功能开发、整改、自动化测试、浏览器验收和候选交付包均已完成；生产外部验收待配置。

## 一、项目概况

本平台是一套面向城市合作伙伴、活动机构和社群组织的多租户活动运营 SaaS。核心业务覆盖活动发布、报名售票、支付退款、会员运营、现场核销、财务对账和多端管理，并通过租户套餐与功能开关按需启用课程社区、多商户商城、公益项目、伙伴招募和志愿者等扩展模块。

当前有效交付状态为“本地候选可交付、生产外部验收待配置”。本地开发剩余周期为 **0**；正式支付、短信、对象存储、域名 HTTPS、外部告警、微信真机、生产灰度和正式签收的周期取决于外部账号、密钥、设备及上线窗口。

## 五、角色说明

| 角色类型 | 主要职责 | 权限边界 |
|---|---|---|
| 平台超级管理员 | 租户、套餐、发布和风险治理 | 可查看跨租户汇总；跨租户明细访问必须审计 |
| 平台运营、客服、财务 | 平台审核、工单支持、对账结算 | 按岗位分权；客服不能修改资金，财务不能修改内容 |
| 租户管理员 | 管理本机构全部业务 | 仅限本租户，仍受套餐权益和平台功能开关约束 |
| 租户运营 | 活动、会员、营销和内容运营 | 无支付密钥、租户安全及资金结算权限 |
| 租户财务 | 订单、退款、对账和结算 | 业务资料原则上只读，退款可受额度和复核限制 |
| 核销员 | 扫码和人工核销 | 仅限授权活动，不显示完整隐私和财务信息 |
| 商户管理员、店员、店铺财务 | 商品、库存、订单、发货、售后和店铺财务 | 仅限所属店铺，不得读取其他商户数据 |
| 讲师、社群管理员 | 课程教学和内容管理 | 仅限被授权课程或社群 |
| 伙伴、大使、志愿者 | 区域合作和生态任务 | 按项目、区域、合同或任务关系授权 |
| 普通会员 | 报名、购买、学习和互动 | 仅能访问本人资产及公开内容 |

最终权限由 **角色权限 + 数据范围 + 套餐权益 + 功能开关** 联合判定；管理 API 从登录身份解析租户，不信任客户端自行传入的租户编号。
