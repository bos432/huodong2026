# 09.03 商城库存治理验收报告

## 1. 验收结论

商城库存锁定、释放、支付扣减、退款回补、库存预警、一致性巡检、人工盘点和并发防超卖已完成开发与本地真实 MySQL/API/浏览器验收。PC 后台、H5 和微信小程序构建通过；微信真机仍按生产配置清单执行最终兼容验收。

## 2. 本轮整改

1. 修复 PC 库存工作台商品摘要缺少店铺运营字段时，所有“调整”按钮被误判禁用的问题。
2. 修复后台商品接口复用公开商城库存序列化的问题。此前后台把可售库存作为总库存并丢失锁定库存，现后台分别返回 `stock`、`lockedStock`、`availableStock`，公开商城仍只暴露可售量。
3. 后台商品摘要补齐店铺 `status`、`onboardingStatus`、`mallEnabled`、`productAuditRequired` 和 `paymentMode`，运营按钮与店铺状态保持一致。
4. 新增库存汇总单测，固定“总库存、锁定库存、可售库存”三个口径。

## 7. 生产终验边界

本功能本身不依赖正式支付密钥即可验证库存锁定和防超卖。微信小程序真机的页面交互、弱网表现及正式支付成功后的库存扣减，需要在正式 AppID、合法域名和支付商户配置就绪后统一终验；该项不影响继续开发后续商城功能。
