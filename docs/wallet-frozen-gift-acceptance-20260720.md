## 一、实现范围

- 钱包按可用现金、冻结现金、可用赠送金、冻结赠送金四个资金桶管理，金额计算统一使用整数分。
- 冻结和解冻支持 `mixed`、`cash`、`gift`。混合模式优先处理赠送金，现金补足；解冻恢复对应资金桶。
- `wallet_transactions` 新增 `frozenGiftBefore/frozenGiftAfter`，所有支付、退款和后台调整均保存四桶快照。
- 哈希 canonical、共享校验器和 MySQL `BEFORE INSERT` 触发器覆盖四桶；migration `1783960000000` 重算所有历史链。
- 后台钱包写接口在钱包悲观锁后以当前读复查幂等键；同键并发返回幂等成功，变更用户、租户、类型、方向或金额复用键返回 409。
- 商城普通余额支付和跨店余额支付将现金/赠送金分摊写入订单快照，部分退款及拼团失败退款按原来源恢复。
- PC 会员详情及 H5 钱包展示四桶和冻结赠送金流水；H5 收支统计排除冻结/解冻内部转移。
