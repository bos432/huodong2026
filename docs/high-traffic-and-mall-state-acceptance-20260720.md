## 实现摘要

### 活动和课程

- 活动列表在租户切换瞬间失效旧请求并清空旧商家数据；列表、分类和装修并发加载，分类失败独立显示且不阻塞主列表，时间统一按上海时区。
- 活动详情使用租户请求代次保护业务数据和装修加载；邀请、日历、举报等动作统一互斥并复核当前活动上下文。
- 活动报名分别保护页面、报价和优惠券请求；报名确认框与附件选择器在打开系统交互前加锁，提交结果复核租户和活动上下文。
- 课程详情分别保护课程、评价和收藏请求；收藏、免费领取和导航只接受当前租户及课程结果。

### 商城列表和会员资产

- 商城首页固定请求时的店铺、分类、排序和关键词快照，拒绝迟到响应；最近搜索按租户存储。
- 购物车、收藏和足迹使用租户请求代次；数量调整、移除和清空结果只写回原租户。
- 删除购物车和清空足迹在确认框出现前加锁，取消和失败均恢复操作状态。

### 商品与确认订单

- 商品加购增加租户动作守卫和商品规格复核；收藏、加购、立即购买和重试补按钮语义、键盘操作及忙碌状态。
- 确认订单为页面、地址、商品、优惠券、报价、支付方式和提交建立独立租户守卫。
- 收货地址选择缓存改为租户键，避免商家切换后复用其他商家的地址 ID。
- 跨店确认框展示前即锁定提交；下单、统一支付和错误处理只接受原提交上下文。
- 物流详情使用租户加订单 ID 的页面上下文，迟到响应和旧订单结果不再覆盖当前页面；复制完成提示也复核同一上下文。

### H5 版本恢复

- 识别 `ChunkLoadError`、`Loading chunk` 和三类动态导入失败文本。
- Vue 错误处理、window error 和 unhandled rejection 均进入恢复逻辑。
- `sessionStorage` 使用 60 秒挡板防止刷新循环；恢复 URL 写入 `__h5_reload` 后使用 `location.replace`。
- API 测试不再跨 `rootDir` 导入 H5 源码，`migration:show` 编译恢复正常。

### 公开凭证验真

- 验真请求捕获编号、凭证类型和请求序号，输入或类型变化会立即使旧请求失效并清除旧结果。
- 迟到的成功或失败响应不能覆盖当前编号；有效期和签发时间统一按上海时区展示。
- 返回、类型标签、编号输入、查询、错误与结果区域补齐按钮、标签页、状态播报和键盘语义。

### 会员钱包

- 页面读取绑定租户、会员 ID 和访问令牌，同租户切换账号时立即清除旧余额和流水；资料、钱包和流水的迟到响应均不能写回新会话。
- 钱包及流水响应执行结构校验，主数据失败显示持久错误而不是零余额；流水时间统一按上海时区展示。
- 加载、错误、空态和重试补状态播报、告警、按钮及键盘语义。

### 会员活动与课程订单

- 页面状态绑定租户、会员 ID 和访问令牌；同租户切换账号时清除旧订单，迟到成功、失败和 loading 不能覆盖新会话。
- 活动报名、学习记录和课程订单三路读取采用部分成功策略；单路失败明确提示失败分区，三路全失败才进入阻塞错误页。
- 退款确认、订单、可退金额和返回结果绑定原会话快照，确认框打开即锁定，取消、失败和成功路径均恢复；服务端继续使用事务锁复用活动中的退款申请。
- 浏览器发现并修复活动部分退款误显示“已退款”，以及课程累计退款误使用最近一笔退款金额；课程订单接口现返回累计已退整数分。
- 筛选、刷新、订单卡片、退款、错误关闭及加载状态补标签页、按钮、键盘与状态播报语义，时间统一按上海时区。

### 会员个人中心

- 主资料及钱包、公益、管理权限、学习、报名、课程订单和商城订单七个资产分区绑定租户、会员 ID 与访问令牌；同租户换账号立即清除旧资产和旧操作错误。
- 主资料改为无本地会话副作用的直接读取并校验对象结构；各资产分区校验数组或对象形状，失败分区显示 `--` 且不污染其他成功数据。
- 功能开关、页面装修和会员资料并发加载，断网只等待一轮请求超时；加载和故障分别显示“资料同步中”与“资料同步失败/状态未知”，不把未知资料伪装成未登录或未绑定。
- 兑换、微信资料同步、手机号绑定回调和退出确认绑定当前会员会话；兑换错误持久展示，退出确认打开即锁定并在取消后恢复。
- “我的订单”角标移除商城订单混算，按活动报名、课程订单及无订单学习资产与目标订单页统一；待观看排除已退款历史单，避免同课程有效新单导致重复计数。

### 移动经营统计

- 请求绑定管理令牌、租户、角色和 7/30/90 天范围；切换管理上下文立即清空旧概览、趋势和渠道，迟到响应不能覆盖新会话。
- 概览、趋势和渠道分别校验响应结构并保留独立错误与重试；主概览失败时清除旧指标，不再把缓存数据与错误状态同时展示。
- 403 不再清除移动管理会话，工作台残留的 403 登录跳转也已收口为仅 401 跳转，最小权限账号不会陷入登录循环。
- 日期统一按 `Asia/Shanghai`，范围标签、刷新、风险入口及错误重试补按钮、键盘和状态播报语义。

### 移动资金异常

- 列表、扫描和处置绑定管理令牌、租户、角色、筛选及告警原状态；切换上下文清除旧数据，迟到响应不能覆盖新会话。
- 主错误与处置错误分层，主请求失败清除旧卡片且只保留一个重试入口；时间统一按上海时区。
- 服务端扫描使用 MySQL 命名锁，处置使用事务悲观行锁和明确状态机；重复请求仅一次实际变更。
- 状态、类型、刷新、扫描、重试和行操作补齐按钮或标签页语义、Enter、Space、忙碌及禁用状态。
