## 2. 宝塔部署命令

```bash
cd /www/wwwroot/rd.chaimen666.com
export PATH=/www/server/nodejs/v22.22.3/bin:$PATH

git fetch origin feature/qiwai-ui-experiment
git pull --ff-only origin feature/qiwai-ui-experiment

npm install --prefix packages/shared
npm install --prefix apps/api
npm install --prefix apps/admin
npm install --prefix apps/mobile --legacy-peer-deps

npm run build
npm --prefix apps/mobile run build:mp-weixin

COMMIT=$(git rev-parse --short HEAD)
BUILD_TIME=$(date -Iseconds)

set_env() {
  FILE="$1"
  KEY="$2"
  VALUE="$3"
  touch "$FILE"
  if grep -q "^${KEY}=" "$FILE"; then
    sed -i "s|^${KEY}=.*|${KEY}=${VALUE}|" "$FILE"
  else
    echo "${KEY}=${VALUE}" >> "$FILE"
  fi
}

set_env ".env" BUILD_COMMIT "$COMMIT"
set_env ".env" BUILD_TIME "$BUILD_TIME"
set_env "apps/api/.env" BUILD_COMMIT "$COMMIT"
set_env "apps/api/.env" BUILD_TIME "$BUILD_TIME"
set_env ".env" API_PORT 18080
set_env "apps/api/.env" API_PORT 18080

pm2 restart activity-api --update-env
sleep 8

curl -i http://127.0.0.1:18080/api/health/ready
curl -i https://rd.chaimen666.com/api/health/ready
curl -s https://rd.chaimen666.com/admin/version.json
curl -s https://rd.chaimen666.com/version.json
```

## 3. Nginx 检查

确认宝塔 Nginx 将 `/api/`、`/install`、`/uploads/` 代理到 `127.0.0.1:18080`。

```bash
CONF=/www/server/panel/vhost/nginx/rd.chaimen666.com.conf
grep -n "127.0.0.1" "$CONF"
nginx -t
/etc/init.d/nginx reload
```

如果仍代理到 `3000`，执行：

```bash
CONF=/www/server/panel/vhost/nginx/rd.chaimen666.com.conf
cp "$CONF" "$CONF.bak.$(date +%Y%m%d%H%M%S)"
sed -i 's|http://127.0.0.1:3000/api/|http://127.0.0.1:18080/api/|g' "$CONF"
sed -i 's|http://127.0.0.1:3000/install|http://127.0.0.1:18080/install|g' "$CONF"
sed -i 's|http://127.0.0.1:3000/uploads/|http://127.0.0.1:18080/uploads/|g' "$CONF"
nginx -t && /etc/init.d/nginx reload
```

服务器或本地构建前设置：

```bash

export VITE_H5_ORIGIN=https://rd.chaimen666.com
export VITE_DEFAULT_TENANT_CODE=qiwai-showcase
```
