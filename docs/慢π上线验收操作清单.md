## 真机验收

使用真实微信扫码体验版，按以下顺序完成并截图留存：

1. 登录或进入演示用户状态。
2. 首页打开一张活动详情，确认标题、时间、地点和状态完整。
3. 进入打卡 Tab，打开“慢π城市观察记录”。
4. 完成至少一个任务，确认进度变化并返回列表。
5. 打开消息、我的和发布入口，确认四个 Tab 可切换。
6. 记录设备脱敏标识、体验版版本、验收人和验收时间。

完成后，在后台“上线验收中心”中更新“真机与体验版验收”。没有真实设备证据时，不要标记为已验收。

## 支付与退款

前置条件：微信支付商户号、商户 API 证书、支付回调地址和退款权限已配置。密钥只写入服务器密钥配置，不写入验收记录或聊天。

1. 使用测试账号创建一笔真实测试订单。
2. 完成支付，核对订单状态、名额和支付回调。
3. 发起退款，核对退款回调、订单状态和名额恢复规则。
4. 保存脱敏订单号、渠道回执摘要和验收时间。
5. 在后台分别更新“支付配置”和“支付/退款回调”。

没有商户号和真实测试订单时，保持“外部验收中”。

## 微信订阅消息

1. 在小程序后台确认模板已启用并绑定正确字段。
2. 真机主动订阅对应模板。
3. 触发一次真实活动提醒或订单状态通知。
4. 保存模板编号脱敏摘要、发送结果和接收时间。
5. 在后台更新“微信订阅消息”。

不要使用后台配置完成或本地 mock 作为送达证据。
