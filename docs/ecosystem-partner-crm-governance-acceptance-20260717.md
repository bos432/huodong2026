## 并发与权限验收

```powershell
npm run acceptance:premium-roles
```

- quota=1 的任务使用任务悲观锁和当前读统计，两路不同业务键并发登记只有一路成功，另一路稳定返回名额已满。
- 同业务键贡献复核、贡献撤销、合同激活、伙伴转换和合同终止均执行并发重放，只推进一次状态和积分。
- 贡献登记人与复核人、合同创建人与复核人强制分离。
- 贡献撤销后积分降回 0，等级回到 `starter`。
- 转换事务同时生成停用租户和可选停用店铺；重放返回原对象，不重复生成主体。

## 缺陷整改

- 修复任务名额并发统计受 Repeatable Read 早期快照影响、两路贡献均成功导致超额的问题；任务锁定后改用带 `pessimistic_read` 的当前读统计占用名额。
- 修复伙伴列表使用 QueryBuilder 时未加载 `convertedTenant` 和 `convertedMerchant`，导致 PC 已转换记录显示 `-` 的问题。
- 列表接口只返回负责人、租户和店铺的必要摘要字段，不向页面暴露租户配置或商户内部字段。
