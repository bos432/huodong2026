## 2026-09-08 全量视觉收口

- `apps/mobile/src/guofeng-ui.css` 已作为全局视觉层接入 `main.ts`，补齐所有页面根容器、公共卡片、表单、状态、页头、后台子页和两套底部导航的统一规则。
- 针对社区、论坛、商城、公益、志愿、合伙人、大使、品牌、用户子页和手机管理子页增加高优先级覆盖，清除残留的棕橙渐变、超大圆角、胶囊操作条和装饰性阴影，保留业务结构、权限和商家配置。
- `pages.json` 中 81 个前端路由已通过本地 H5 路由 smoke：均能渲染非空页面，没有编译错误或空白页；其中需要接口数据的页面在本机 API 未启动时展示受控错误/空态，这是验收环境状态，不是 UI 回归。
- 重点截图复核：品牌故事、设置、社区、商城、论坛、城市合伙人、我的心得、商城优惠券、商城订单、手机管理首页、报名审核、签到核销、资金异常和活动编辑页。

## 尚未逐页重设计

源码中共有 81 个页面文件。本轮已通过全局视觉收口覆盖全部路由；仍不把每个页面宣称为独立草图重设计，动态接口有数据时需继续抽查内容密度、图片比例和角色权限状态。

- 登录后的订单、报名凭证、钱包、资料、安全设置、常用报名人、评价等独立页面：沿用既有结构，基础变量会继承新配色，但不等于逐页完成本次草图设计或登录后验收。
- 专题内容、社区、论坛、商城、公益、志愿者、合作招募、手机管理等独立模块：已统一全局视觉基础和公共交互表面；保持原功能开关与角色权限，不因为验收而临时开放。
- 微信小程序本轮检查编译和产物依赖；真机、微信授权与审核发布需单独完成。

## 发布边界

- H5 静态包按版本备份后发布，保留旧哈希资源。
- 不改数据库、权限、支付、通知或其他服务；本地与服务器测试数据全部保留。
- 小程序必须重新上传体验版并提交审核，不能把 H5 发布当作微信正式版已生效。
