# 优化整改记录

## 已执行整改
本轮验收过程中发现的问题已直接修复并复测通过。

### 1. 商家角色缺少论坛权限
问题：
- 新增论坛后，商家默认权限和演示 seed 权限未包含 `forum.manage`、`forum.moderate`。

整改：
- 后台默认商家管理员权限补充论坛管理和审核权限。
- 演示账号 seed 权限补充论坛管理和审核权限。

验证：
- 后台「共修动态」下可看到「论坛管理」页签。
- `npm run browser:operations-forum` 通过。

### 2. 默认入口城市未在演示 seed 中固定
问题：
- 演示环境如果没有配置默认入口城市，首次进入可能不是 `qiwai-showcase`。

整改：
- `seed-online-showcase` 自动写入平台全局 `defaultTenantCode=qiwai-showcase`。

验证：
- `/api/public/tenants/bootstrap` 返回默认商家 `qiwai-showcase`。
- H5 清空本地商家缓存后进入论坛，仍能进入默认商家内容。

### 3. 论坛回复递归 eager 查询导致详情接口异常
问题：
- 论坛回复 `parent` 使用 eager 关系，楼中楼数据在 TypeORM 加载时可能递归，导致接口 500 或超时。

整改：
- 移除 `ForumReply.parent` 的 eager 加载。
- 需要父级和主题时显式声明 `relations`，并设置 `loadEagerRelations: false`。

验证：
- `GET /public/forum/topics/:id?tenantCode=qiwai-showcase` 返回 200。
- 论坛详情浏览器验收通过。

### 4. 拼团 smoke 时间窗口不稳定
问题：
- smoke 测试使用当前时间前后几分钟构造拼团，机器时间或执行时机可能导致误判“尚未开始”。

整改：
- 演示 seed 和 smoke 测试改为固定宽时间窗口，避免时间边界不稳定。

验证：
- `npm run smoke:online-showcase` 通过，拼团开团、参团、成团、退款兜底均正常。

### 5. H5 发帖页浏览器验收选择器不兼容 uni-app DOM
问题：
- uni-app H5 将 placeholder 渲染为占位 `div`，真实输入框无 placeholder 属性，导致浏览器验收脚本无法填发帖表单。

整改：
- 专项浏览器脚本改用 uni-app H5 实际 DOM 选择器填表。

验证：
- H5 论坛发帖页验收通过。

### 6. 本地 API 版本元数据不一致
问题：
- 本地 Docker API 的 `BUILD_COMMIT` 是旧占位值，浏览器验收出现版本 warning。

整改：
- 用当前提交和构建时间重启本地 API 容器。

验证：
- 主浏览器验收版本检查通过：API、Admin、H5 均为 `480f5153`。

### 7. 新增专项验收脚本
整改：
- 新增 `npm run smoke:operations-forum`。
- 新增 `npm run browser:operations-forum`。

覆盖：
- 默认城市入口。
- 六个运营 overview。
- 完整论坛 v1。
- 志愿者证书发放、核验、撤销。
- H5 论坛和后台默认入口配置。
