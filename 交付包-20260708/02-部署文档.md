# 部署文档

## 部署目标
将 `feature/qiwai-ui-experiment` 分支部署到宝塔服务器 `/www/wwwroot/rd.chaimen666.com`，更新 API、H5、后台静态资源，并运行数据库迁移。

## 宝塔终端命令
在宝塔终端执行：
```bash
cd /www/wwwroot/rd.chaimen666.com
export PATH=/www/server/nodejs/v22.22.3/bin:$PATH

git fetch origin feature/qiwai-ui-experiment
git checkout feature/qiwai-ui-experiment
git pull --ff-only origin feature/qiwai-ui-experiment

npm install --prefix packages/shared
npm install --prefix apps/api
npm install --prefix apps/admin
npm install --prefix apps/mobile --legacy-peer-deps

npm run build
npm --prefix apps/api run migration:run
npm run publish:webroot

COMMIT=$(git rev-parse --short HEAD)
NOW=$(date -Iseconds)
export BUILD_COMMIT="$COMMIT"
export BUILD_TIME="$NOW"

PM2=/www/server/nodejs/v22.22.3/lib/node_modules/pm2/bin/pm2
$PM2 restart activity-api --update-env
$PM2 save

curl -i --max-time 10 https://rd.chaimen666.com/api/health
curl -i --max-time 10 https://rd.chaimen666.com/version.json
curl -i --max-time 10 https://rd.chaimen666.com/api/public/tenants/bootstrap
```

## 预期结果
- `/api/health` 返回 HTTP 200，JSON 中 `api` 和 `database` 为 `up`。
- `/version.json` 返回 H5 静态版本。
- `/api/public/tenants/bootstrap` 返回城市列表和默认城市，默认商家应包含 `qiwai-showcase` 或后台实际配置的默认商家。
- 后台可访问：`https://rd.chaimen666.com/admin/login`
- H5 可访问：`https://rd.chaimen666.com/?tenantCode=qiwai-showcase#/`

## 502 排查命令
如果 `/api/health` 返回 502，优先看 API 日志：
```bash
cd /www/wwwroot/rd.chaimen666.com
PM2=/www/server/nodejs/v22.22.3/lib/node_modules/pm2/bin/pm2
$PM2 status
$PM2 logs activity-api --lines 120
```

常见原因：
- API 进程未启动或启动后崩溃。
- 数据库迁移失败或数据库连接配置不正确。
- PM2 使用的 Node 版本不是 `/www/server/nodejs/v22.22.3/bin/node`。
- Nginx 反代端口与 API 实际端口不一致。

## 数据库迁移说明
本轮包含默认城市、论坛、证书等表结构和字段。部署时必须执行：
```bash
npm --prefix apps/api run migration:run
```

不要在生产环境开启 `DB_SYNCHRONIZE=true`。生产应使用迁移脚本演进表结构。

## 本地 GitHub 拉取失败处理
如果本地 PowerShell 出现 `Failed to connect to github.com port 443 via 127.0.0.1`，说明 Git 配了本机代理但代理未启动。可临时跳过代理：
```powershell
git -c http.proxy= -c https.proxy= pull origin feature/qiwai-ui-experiment
```

也可以检查并清理全局代理：
```powershell
git config --global --get http.proxy
git config --global --get https.proxy
git config --global --unset http.proxy
git config --global --unset https.proxy
```
