# 交付操作教程

## 1. 登录入口
- 后台：`https://rd.chaimen666.com/admin/login`
- H5：`https://rd.chaimen666.com/?tenantCode=qiwai-showcase#/`
- 小程序：微信开发者工具导入 `apps/mobile/dist/build/mp-weixin`，上传体验版后扫码测试。

## 2. 默认城市入口配置
操作路径：
1. 使用平台超管登录后台。
2. 进入「系统设置」。
3. 找到「默认入口城市/商家」。
4. 选择要作为用户首次打开小程序默认进入的城市或商家。
5. 保存后打开接口确认：`https://rd.chaimen666.com/api/public/tenants/bootstrap`

入口优先级：
1. 分享链接中的 `tenantCode`。
2. 用户手动选择的城市/商家。
3. 定位匹配到的城市。
4. 后台配置的默认城市/商家。
5. 构建默认值。
6. 第一个可用商家。

## 3. 功能开放控制
操作路径：平台超管登录后台 ->「系统设置」->「功能开放」。

用途：
- 已开发但暂不对用户开放的模块，可以先关闭入口。
- 超管仍可进入系统设置调整开关。
- 关闭后会隐藏小程序入口、首页装修链接、「我的」页面入口、广告位和非超管后台菜单。

推荐交付策略：
1. 初期选择「基础活动 + 心得」：保留活动报名、活动心得和基础会员能力。
2. 暂时关闭课程、论坛、商城、公益池、志愿服务、证书、文化大使、广告招商、城市合伙人和代理结算。
3. 每个模块准备好内容、运营人员和审核规则后，再逐项打开。
4. 保存后，重新打开 H5 或小程序体验版确认入口变化。

注意：
- 这个开关不删除数据，只控制入口和普通角色可见性。
- 如果首页装修里配置了已关闭模块的按钮，前台会自动隐藏或拦截。
- 小程序体验版如仍显示旧入口，先删除小程序本地缓存或重新扫码体验版。

## 4. 公益池运营
操作路径：后台「公益池」。

常用流程：
1. 查看公益总览：可用余额、累计计提、累计拨付、公开项目数、待执行和待验收项目。
2. 新建公益项目，填写项目说明和公开状态。
3. 登记拨付记录，上传凭证。
4. 发布执行动态。
5. 检查透明度提醒：有拨付无凭证、有项目无动态、已执行未验收。

验收标准：
- 前台公开项目能看到项目说明和执行动态。
- 后台项目详情能看到资金流、拨付记录、执行动态、公开状态和凭证入口。

## 5. 文化大使招募
操作路径：后台「文化大使」。

常用流程：
1. 查看线索看板：待跟进、高意向、待面谈、已激活、超期未跟进。
2. 在线索列表查看来源、优先级、五项评分、下一次跟进时间、最近跟进结果。
3. 打开快捷跟进抽屉，修改状态、写跟进记录、设置下次跟进、更新评分。
4. 激活后进入志愿者或大使档案和证书体系。

## 6. 志愿者档案和证书
操作路径：后台「志愿者」。

任务闭环：
1. 发布志愿任务。
2. 用户报名任务。
3. 后台审核报名。
4. 登记服务记录。
5. 系统累计服务时长并更新等级。
6. 后台发放证书。
7. 用户在前台「我的证书」查看。
8. 通过证书编号做公开核验。

证书 v1 模板：
- 慢π公益志愿服务证书。
- 公益大使证书。
- 城市共建者证书。

后台支持：
- 发证。
- 补发。
- 查看。
- 下载或打印。
- 撤销，撤销会保留操作日志。

## 7. 课程管理
操作路径：后台「课程管理」。

常用流程：
1. 新建课程，填写封面、讲师头像、分类、标签、排序、评分和热度展示。
2. 配置章节课时，设置课时序号和免费试看。
3. 发布课程。
4. 用户下单。
5. 后台确认收款。
6. 用户获得学习权限并记录学习进度。

注意：
- 章节保存前不能留空标题。
- 付费课程订单要优先处理待确认收款。

## 8. 共修动态
操作路径：后台「共修动态」。

常用流程：
1. 查看共修运营看板：共修活动、打卡任务、待审核动态、待审核评论、今日互动。
2. 审核用户动态和评论。
3. 对拒绝内容填写备注。
4. 检查打卡任务完成数和重复任务提醒。

## 9. 完整论坛 v1
前台入口：H5 或小程序「共修论坛」。
后台入口：后台「共修动态」下的「论坛管理」页签。

后台流程：
1. 新建版块，配置名称、简介、排序、启用状态、发帖权限和审核模式。
2. 用户发帖后进入待审。
3. 后台审核帖子。
4. 对优质帖子设置置顶或精华。
5. 审核回复和楼中楼回复。
6. 处理举报，填写处理备注。

前台流程：
1. 进入论坛首页。
2. 选择版块。
3. 查看帖子详情。
4. 登录后发帖、回复、楼中楼回复。
5. 收藏帖子。
6. 举报帖子或回复。
7. 在「我的帖子」「我的回复」「我的收藏」查看记录。

审核规则：
- 默认审核制。
- 前台只展示 `approved` 内容。
- 小程序审核版可以隐藏发帖入口，只展示已审核内容。

## 10. 活动报名和未登录跳转
用户未登录时查看活动可以正常浏览。点击报名时会跳转登录，登录后回到原本要报名的活动位置继续报名。

测试方式：
1. 退出 H5 或小程序登录。
2. 打开活动详情页。
3. 点击报名。
4. 完成手机号验证码登录。
5. 确认回到报名页并保留当前活动。

## 11. 活动心得图片发布
前台发布心得支持图片上传。iPhone 测试建议用微信开发者工具体验版或真机体验版验证：
1. 登录用户。
2. 进入已参加活动。
3. 点击发布心得。
4. 选择照片。
5. 提交后后台审核。
6. 审核通过后前台展示。

## 12. 微信小程序上传步骤
1. 在本地项目根目录拉取代码：
```powershell
cd "E:\2027\活动报名\活动报名"
git pull origin feature/qiwai-ui-experiment
```

2. 编译小程序：
```powershell
npm --prefix apps/mobile run build:mp-weixin
```

3. 打开微信开发者工具。
4. 选择「导入项目」。
5. 目录选择：
```text
E:\2027\活动报名\活动报名\apps\mobile\dist\build\mp-weixin
```

6. 填写小程序 AppID。
7. 在开发者工具中预览，确认首页、活动详情、报名、登录、论坛、我的证书。
8. 点击「上传」生成体验版。
9. 到微信公众平台提交审核。

注意：
- 不要导入仓库根目录。
- 不需要手动选择 `apps/mobile` 作为开发者工具目录。
- `npm --prefix apps/mobile run build:mp-weixin` 必须在仓库根目录执行。
- 小程序默认 API 为 `https://rd.chaimen666.com/api`，需要在微信公众平台配置合法域名。
- 如果本机 Node v25 导致 `uni build -p mp-weixin` 只显示“正在编译中”后退出，切换到 Node 22 或 Node 24 再编译。
