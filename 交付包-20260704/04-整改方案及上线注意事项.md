# 整改方案及上线注意事项

## 已完成整改

### 1. 手机端管理端保存/发布反馈不明显

现象：

- 用户点击保存或发布后感觉“没反应”。
- 必填项缺失时只 toast，容易被忽略。

整改：

- 活动编辑页新增固定操作提示区域。
- 校验失败会跳到对应步骤，例如标题缺失跳回基础页。
- 保存/发布时按钮显示“保存中...”或“发布中...”。
- 重复点击时会被拦截。

状态：已修复并通过 H5 等价页面真实点击验收。

### 2. 已上线活动再次编辑状态不稳

现象：

- 已上线活动保存后可能被按草稿逻辑处理。

整改：

- 已上线活动保存时目标状态保持 `open`。
- 待审活动保存时目标状态保持 `pending_approval`。
- 新建活动按商家配置显示“发布”或“提交审核”。

状态：API 复测通过。

### 3. 未开通报名审核权限时保存失败

现象：

- 商家未开通报名审核，但前端可能提交 `requireReview=true`。
- 接口拒绝后表现为保存失败。

整改：

- 手机端按商家配置禁用报名审核开关。
- 保存 payload 自动按权限兜底。
- API 层保留权限校验。

状态：已修复。

### 4. 小程序接口地址兜底

现象：

- 小程序包如果没有拿到构建环境变量，可能请求不到正确 API。

整改：

- mp-weixin 默认 API 地址兜底为 `https://rd.chaimen666.com/api`。

状态：已修复。

### 5. 入群二维码流程补齐

现象：

- 运营找不到“报名完成后的群二维码”在哪里设置。

整改：

- 手机端活动发布页“报名”步骤增加“报名成功入群二维码”。
- 可上传图片或粘贴图片链接。
- 公开活动页不直接展示二维码，报名成功详情页展示。

状态：已补齐。

## 当前剩余风险

### 1. 小程序必须重新审核

本次修复涉及小程序端源码。没有重新上传和审核时，手机用户仍会使用旧包，所以会继续看到旧问题。

处理方式：

1. 构建 `mp-weixin`。
2. 微信开发者工具上传体验版。
3. 体验版复测手机管理端发布活动。
4. 提交审核。
5. 审核通过后发布正式版。

### 2. 当前环境不能直接唤起微信开发者工具

本机只有微信开发者工具 `User Data` 目录，没有可执行程序或 CLI。

影响：

- 不能在当前 Codex 环境里直接上传体验版。
- 已用 mp-weixin 编译产物检查和 H5 等价页面验收替代。

### 3. 平台超管和杭州商家旧默认密码不可用

线上复测结果：

- `admin / Admin123456` 返回 401。
- `qiwai_hz_* / Qiwai123456` 返回 401。

影响：

- 平台审核流无法在线上完成实点复测。

处理方式：

- 提供实际平台超管密码，或在数据库/后台重置。
- 重置后补测：商家提交审核、平台审核通过、活动变报名中。

### 4. 服务器环境文件不能随意覆盖

之前把 `deploy/.env.production` 覆盖到线上 `.env` 后出现 502，原因是数据库主机配置不匹配。

处理方式：

- 部署命令不复制 `.env`。
- 继续使用服务器现有 `.env` 和 `apps/api/.env`。

### 5. 阿里云系统安全更新提醒

服务器登录时提示有安全更新。

处理方式：

- 这不是本次业务代码问题。
- 建议另选低峰期做系统补丁维护，并提前快照备份。

## 后续优化建议

建议后续排期，不阻塞本次上线：

1. 手机端管理端增加“当前商家发布规则”说明，明确显示“直接发布”或“提交平台审核”。
2. PC 后台增加“复制活动为新活动”能力，减少运营重复录入。
3. 小程序上传发布接入 CI 或后台小程序发布模块，减少人工导入目录。
4. 将线上验收拆成轻量版和全量版，轻量版只跑登录、活动发布、报名、签到。
5. 为平台超管和商家账号建立正式交付账号清单，避免默认密码被修改后无人知道。
