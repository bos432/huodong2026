# 部署文档

适用环境：宝塔 Linux 服务器
站点目录：`/www/wwwroot/rd.chaimen666.com`
分支：`feature/qiwai-ui-experiment`
当前推荐部署提交：`bb846179` 或更新提交

## 重要提醒

1. 不要把 `deploy/.env.production` 直接覆盖到服务器 `.env` 或 `apps/api/.env`。之前覆盖后出现过 `DB_HOST=mysql` 导致线上 502。
2. 服务器部署只会更新 API、PC 后台和 H5 静态资源，不会自动更新微信小程序正式版/体验版。
3. 本次涉及 `apps/mobile` 小程序端代码，必须重新上传小程序并提交审核。
4. 当前是上线运营阶段，部署前建议先做数据库备份。

## 宝塔终端部署命令

```bash
cd /www/wwwroot/rd.chaimen666.com
set -e

PM2=/www/server/nodejs/v22.22.3/lib/node_modules/pm2/bin/pm2

git fetch origin
git pull --ff-only origin feature/qiwai-ui-experiment
COMMIT=$(git rev-parse --short HEAD)
NOW=$(date -Iseconds)

# 更新发布标识。只改 BUILD_COMMIT / BUILD_TIME，不覆盖数据库、域名、密钥等线上配置。
set_env_value() {
  FILE="$1"
  KEY="$2"
  VALUE="$3"
  touch "$FILE"
  if grep -q "^${KEY}=" "$FILE"; then
    sed -i "s|^${KEY}=.*|${KEY}=${VALUE}|" "$FILE"
  else
    printf '\n%s=%s\n' "$KEY" "$VALUE" >> "$FILE"
  fi
}
set_env_value .env BUILD_COMMIT "$COMMIT"
set_env_value .env BUILD_TIME "$NOW"
set_env_value apps/api/.env BUILD_COMMIT "$COMMIT"
set_env_value apps/api/.env BUILD_TIME "$NOW"
export BUILD_COMMIT="$COMMIT"
export BUILD_TIME="$NOW"

# 备份数据库；如果备份脚本依赖的环境缺失，这一步失败不阻断后续部署
npm run db:backup || true

# 数据库迁移。没有新迁移时会直接跳过，保留执行可以防止字段缺失。
npm --prefix apps/api run migration:run

# 构建后端和 PC 后台
npm --prefix apps/api run build
npm --prefix apps/admin run build

# 构建 H5 和小程序包
export VITE_API_BASE=https://rd.chaimen666.com/api
export VITE_DEFAULT_TENANT_CODE=qiwai-showcase
npm --prefix apps/mobile run build:h5
npm --prefix apps/mobile run build:mp-weixin

# 重启 API
if $PM2 describe activity-api >/dev/null 2>&1; then
  export BUILD_COMMIT="$COMMIT"
  export BUILD_TIME="$NOW"
  $PM2 restart activity-api --update-env
else
  $PM2 restart all --update-env
fi
$PM2 save

# 重载 Nginx
/www/server/nginx/sbin/nginx -t
/www/server/nginx/sbin/nginx -s reload

# 健康检查阶段不要再用 set -e + curl -f，避免 502 时宝塔终端直接退出
set +e
echo "等待 API 进程启动..."
sleep 8

echo "PM2 状态："
$PM2 list

echo "本机 API 存活检查："
curl -i --max-time 10 http://127.0.0.1:3000/api/health/live
LOCAL_LIVE=$?

echo "本机 API 就绪检查："
curl -i --max-time 10 http://127.0.0.1:3000/api/health/ready
LOCAL_READY=$?

echo "公网 API 检查："
curl -i --max-time 10 https://rd.chaimen666.com/api/health
PUBLIC_HEALTH=$?
curl -i --max-time 10 https://rd.chaimen666.com/api/health/ready
PUBLIC_READY=$?
echo "当前发布提交：$COMMIT"

echo "静态版本检查："
curl -i --max-time 10 https://rd.chaimen666.com/admin/version.json
curl -i --max-time 10 https://rd.chaimen666.com/version.json

if [ "$LOCAL_LIVE" -ne 0 ] || [ "$LOCAL_READY" -ne 0 ] || [ "$PUBLIC_HEALTH" -ne 0 ] || [ "$PUBLIC_READY" -ne 0 ]; then
  echo "健康检查未全部通过，打印最近 API 日志，但不让终端断开："
  $PM2 logs activity-api --lines 120 --nostream
fi
```

## 小程序重新上传审核

结论：需要重新提交小程序审核。

原因：本次修复包含 `apps/mobile/src/pages/admin/activity/edit.vue`、手机端 API 兜底和发布反馈逻辑，正式版小程序只有审核发布后才会更新。

操作流程：

1. 在本地或服务器执行：
   ```bash
   npm --prefix apps/mobile run build:mp-weixin
   ```
2. 打开微信开发者工具。
3. 导入目录：
   ```text
   apps/mobile/dist/build/mp-weixin
   ```
4. 上传为体验版，备注建议：
   ```text
   修复手机端管理端活动保存/发布反馈和状态保持问题
   ```
5. 用体验版复测：
   - `showcase_ops / Qiwai123456` 登录手机管理端。
   - 点击发布活动。
   - 空表单点保存，应提示“请填写活动标题”。
   - 填完整活动标题、介绍、地点、详情后点击发布，应进入报名中。
   - 已上线活动再次编辑保存，应保持报名中。
6. 体验版通过后提交审核。
7. 审核通过后发布正式版。

const base = "https://rd.chaimen666.com/api";
const run = async () => {
  const login = await fetch(`${base}/admin/auth/login`, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ username: "showcase_ops", password: "Qiwai123456" })
  }).then((res) => res.json());
  if (login.code !== 0) throw new Error(login.message || "login failed");
  const token = login.data.token;
  const boot = await fetch(`${base}/admin/mobile/bootstrap`, {
    headers: { authorization: `Bearer ${token}` }
  }).then((res) => res.json());
  if (boot.code !== 0) throw new Error(boot.message || "bootstrap failed");
  console.log("mobile admin ok:", boot.data.admin.username, boot.data.permissions);
};
run().catch((err) => { console.error(err); process.exit(1); });

## 回滚建议

如果部署后 API 健康检查失败：

1. 先看日志：
   ```bash
   PM2=/www/server/nodejs/v22.22.3/lib/node_modules/pm2/bin/pm2
   $PM2 logs activity-api --lines 200
   ```
2. 检查是否误覆盖 `.env`。
3. 回到上一稳定提交：
   ```bash
   cd /www/wwwroot/rd.chaimen666.com
   git log --oneline -5
   git checkout <上一稳定提交>
   npm --prefix apps/api run build
   npm --prefix apps/admin run build
   export VITE_API_BASE=https://rd.chaimen666.com/api
   export VITE_DEFAULT_TENANT_CODE=qiwai-showcase
   npm --prefix apps/mobile run build:h5
   PM2=/www/server/nodejs/v22.22.3/lib/node_modules/pm2/bin/pm2
   $PM2 restart activity-api --update-env
   /www/server/nginx/sbin/nginx -t
   /www/server/nginx/sbin/nginx -s reload
   ```
4. 数据库迁移不建议盲目回滚，除非已确认迁移可逆且有备份。
