# 部署文档

适用环境：宝塔 Linux 服务器
站点目录：`/www/wwwroot/rd.chaimen666.com`
分支：`feature/qiwai-ui-experiment`

## 部署前确认

1. 当前是线上运营阶段，部署前建议先在宝塔或命令行确认数据库备份。
2. 本次包含 API、PC 管理后台、H5、小程序端改动。
3. 本次必须执行数据库迁移，否则可能出现 `launchConfig` 等字段缺失导致后台接口异常。

## 宝塔终端部署命令

```bash
cd /www/wwwroot/rd.chaimen666.com
set -e

git fetch origin
git pull --ff-only origin feature/qiwai-ui-experiment

# 建议先备份数据库；如果线上已配置备份脚本，这一步会生成备份文件
npm run db:backup || true

# 数据库迁移，必须执行
npm --prefix apps/api run migration:run

# 后端与前端构建
npm --prefix apps/api run build
npm --prefix apps/admin run build

export VITE_API_BASE=https://rd.chaimen666.com/api
export VITE_DEFAULT_TENANT_CODE=qiwai-showcase
npm --prefix apps/mobile run build:h5
npm --prefix apps/mobile run build:mp-weixin

# 重启 API
if pm2 describe activity-api >/dev/null 2>&1; then
  pm2 restart activity-api --update-env
else
  pm2 restart all --update-env
fi
pm2 save

/www/server/nginx/sbin/nginx -t
/www/server/nginx/sbin/nginx -s reload

# 部署后健康检查
curl -fsS https://rd.chaimen666.com/api/health
curl -fsS https://rd.chaimen666.com/api/health/ready
```

## 小程序发布

本次改动包含 `apps/mobile/src/pages/admin/activity/edit.vue`，所以需要重新上传小程序。

推荐流程：

1. 执行上面的 `npm --prefix apps/mobile run build:mp-weixin`。
2. 打开微信开发者工具，导入：
   - `apps/mobile/dist/build/mp-weixin`
3. 上传为体验版。
4. 用体验版重点复测：
   - 手机管理端登录。
   - 新建活动保存草稿。
   - 可直发商家发布活动。
   - 需平台审核商家提交审核。
   - 已上线活动编辑后保存仍为报名中。
   - 未开通报名审核商家不能打开报名审核。
5. 提交审核。
6. 审核通过后发布上线。

结论：需要重新提交小程序审核。

## 回滚建议

如果部署后出现严重问题：

1. 不要清理测试数据或手工改核心表。
2. 先保存当前日志：
   ```bash
   pm2 logs --lines 200
   ```
3. 使用 Git 回到上一稳定提交：
   ```bash
   cd /www/wwwroot/rd.chaimen666.com
   git log --oneline -5
   git checkout <上一稳定提交>
   npm --prefix apps/api run build
   npm --prefix apps/admin run build
   export VITE_API_BASE=https://rd.chaimen666.com/api
   export VITE_DEFAULT_TENANT_CODE=qiwai-showcase
   npm --prefix apps/mobile run build:h5
   pm2 restart activity-api --update-env || pm2 restart all --update-env
   /www/server/nginx/sbin/nginx -t && /www/server/nginx/sbin/nginx -s reload
   ```
4. 数据库迁移通常不建议回滚，除非明确知道该迁移可逆且已备份。
