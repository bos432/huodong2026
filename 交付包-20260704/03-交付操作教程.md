## 手机端管理端发布活动

适用账号：`showcase_ops / Qiwai123456` 或商家管理员账号。

操作步骤：

1. 打开最新小程序体验版或 H5。
2. 进入“我的”。
3. 点击“手机管理端”。
4. 输入后台账号和密码登录。
5. 点击“发布活动”。
6. 在“基础”页填写：
   - 活动标题
   - 活动介绍
   - 地点
   - 开始时间、结束时间、报名截止
   - 名额、价格
   - 地图链接，可选
7. 在“报名”页设置：
   - 报名审核开关
   - 允许取消
   - 推荐展示
   - 报名成功入群二维码
   - 报名字段
8. 在“详情”页填写：
   - 主办方/讲师，可选
   - 详情内容模块
   - 报名须知
9. 点击“保存”或“发布”。

提示：

- 空表单直接保存会提示“请填写活动标题”，不是无反应。
- 展示商家当前可直接发布，发布后状态为“报名中”。
- 已上线活动再次编辑时，按钮显示“保存上线”，保存后仍保持报名中。
- 如果商家配置为需要平台审核，手机端会显示“提交审核”，不能直接发布。

## 入群二维码在哪里

位置：手机端管理端发布/编辑活动页，“报名”步骤里的“报名成功入群二维码”。

规则：

- 可以上传二维码图片，也可以粘贴二维码图片链接。
- 公开活动详情页不会直接展示二维码，避免未报名用户扫码入群。
- 用户报名成功后，在报名详情页查看入群提示/二维码。
- 如果活动没有单独设置二维码，可使用运营设置里的默认群二维码。

交付时建议这样说明给运营：

1. 每个活动都可以单独设置入群二维码。
2. 二维码只给报名成功的人看。
3. 如果临时换群，编辑活动后替换二维码即可。

## PC 后台活动管理

地址：`https://rd.chaimen666.com/admin/`

常用流程：

1. 使用商家管理员或运营账号登录。
2. 进入“活动管理”。
3. 点击新建活动或编辑活动。
4. 设置标题、封面、介绍、地点、时间、报名字段、详情内容。
5. 设置报名成功入群二维码。
6. 保存或发布。

平台审核流程：

1. 使用平台超管登录。
2. 进入“活动审核”或“活动管理”，筛选待审活动。
3. 打开活动详情。
4. 审核通过或驳回。

注意：本轮线上 `admin / Admin123456` 不可用，平台审核流需要实际平台超管密码才能操作。

## 首页装修图片广告

位置：PC 管理后台 `首页装修`。

操作步骤：

1. 登录 PC 管理后台。
2. 进入“首页装修”。
3. 找到“图片广告”模块。
4. 添加多张图片。
5. 每张图片都可以单独设置跳转链接。
6. 保存装修。
7. 前台首页刷新后检查展示和跳转。

说明：

- 图片广告不是只能上传一张。
- 每张图独立配置链接，适合跳活动详情、商品页、专题页等。

## 用户报名

用户端流程：

1. 用户打开小程序或 H5 首页。
2. 进入活动详情。
3. 点击报名。
4. 登录或填写手机号验证码。
5. 填写报名字段。
6. 提交报名。
7. 免费免审活动会直接报名成功。
8. 需审核活动会进入待审核。
9. 报名成功后，在报名详情页查看入群提示/二维码。

本地开发环境验证码通常为 `123456`。线上如果接入短信服务，以短信收到的验证码为准。

## 报名审核

适用账号：商家管理员或运营。

1. 登录 PC 后台或手机端管理端。
2. 进入“报名审核”或“报名管理”。
3. 筛选待审核报名。
4. 查看报名资料。
5. 点击通过或拒绝。

## 财务确认线下收款

适用账号：`showcase_finance / Qiwai123456`。

1. 登录 PC 管理后台。
2. 进入订单或财务页面。
3. 搜索订单号、手机号或活动名称。
4. 找到待付款订单。
5. 点击确认收款。
6. 填写备注并保存。

## 签到核销

适用账号：`showcase_checkin / Qiwai123456`。

1. 用户打开报名详情，展示签到码。
2. 核销员登录手机端管理端或 PC 后台。
3. 进入签到核销。
4. 输入或扫描签到码。
5. 点击核销。
6. 核销成功后报名记录变为已签到。

## 交付前必须确认

1. 小程序是否已经上传最新体验版。
2. 最新体验版是否已经提交审核。
3. 审核通过后是否发布正式版。
4. 平台超管真实账号密码是否已交付。
5. 杭州商家账号是否需要重置或重新创建。
6. 线上短信、支付、备案域名是否已按正式运营要求配置。
